# strasbourg-landcover-classifier

Classify 250 m Sentinel-2 tiles over Strasbourg into land-cover classes using OSM labels —
from Google Earth Engine download to a full-area prediction map (macro-F1 0.84).

## Pipeline (run in this order, with the `cpu` micromamba env)

| script | goal | output |
|---|---|---|
| `code/01b_gee.py` | download cloud-masked summer-2025 S2 median composite (10 bands, 10 m, EPSG:32632) | `data/img/s2_stack.tif` |
| `code/02_tile_grid.py` | 126×146 grid of 250 m tiles | `data/img/tile_grid.parquet` |
| `code/03_labels.py` | rasterize OSM labels, majority class ≥ 60 % per tile | `data/labels/tile_labels.parquet` |
| `code/04_features.py` | 38 spectral features per tile (band stats, NDVI, NDWI, NDBI, fractions) | `data/features/features.parquet` |
| `code/05_split.py` | spatial-block train/test split (≈3.5 km blocks, no random leakage) | `data/processed/split.parquet` |
| `code/06_model.py` | benchmark dummy / logreg / RF / HistGB, save best | `results/` |
| `code/07_evaluate.py` | confusion matrix + summary for the report | `results/` |
| `code/08_predict_map.py` | classify **every** tile → full-area map + confidence | `results/` |

## Results (spatially held-out test blocks)

| model | macro-F1 | accuracy |
|---|---|---|
| dummy (majority) | 0.129 | 0.475 |
| logistic regression | 0.839 | 0.894 |
| random forest | 0.827 | 0.902 |
| **HistGradientBoosting** | **0.841** | **0.922** |

Per class: water 0.98 · built-up 0.94 · farmland 0.94 · forest 0.91 · grass 0.44 (weakest:
only 361 samples, spectrally between farmland and forest).

Key artefacts: `results/predicted_map.tif`, `results/predicted_map_overview.png`,
`results/confusion_matrix.png`, `results/prediction_table.parquet` (class + confidence for
all 18 396 tiles), `results/summary.md`.

## GEE access

`code/01b_gee.py` authenticates through a Google Cloud **service-account key**
(`strasbourg-classification-*.json`, stored in the project root and **excluded from git**,
see `.gitignore`). The registered service account is
`my-app-strasbourg-service@strasbourg-classification.iam.gserviceaccount.com`.

## Data

- `data/shape/` (OSM shapefiles) are **not in git** — re-download them from
  [Geofabrik](https://download.geofabrik.de/europe/france/alsace.html) or your
  course's OSM export, and drop them in `data/shape/`.
- `data/img/s2_stack.tif` is regenerated by `code/01b_gee.py` (needs a GEE
  service-account key in the project root).

## Study area

7.55–8.04 °E, 48.43–48.72 °N (Eurométropole de Strasbourg), in EPSG:32632, 10 m pixels.
Classes: water · forest · grass · farmland · built-up.
